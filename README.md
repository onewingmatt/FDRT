# FDRT — Formula D Race Tools

Track generation utilities and board calibration helpers for Formula D racing.

- `generate_track_coordinates.py` — Create track layouts from parameters
- `generate_variable_width_track.py` — Race tracks with non-uniform width
- `formula_d_game.py` — Game logic engine
- `detect_track.py` — Read track layouts from images
- `coordinate_validation.html` — Visual checker for track coordinates
- `calibrate_board.html` — Board/tablet calibration tool
